# Пз5 - React-клієнт, основи

Чотири практичні ваш сервер спілкувався з `curl`. Сьогодні в проєкті
зʼявляється те, що бачить користувач.

У Пз1 клієнта не було навмисно: спершу треба було, щоб сервер відповідав.
Тепер є що показувати. Каркас клієнта вже зібраний (Vite, проксі, стилі) -
щоб пара пішла на React, а не на налаштування збірника. Як створити такий
проєкт із нуля однією командою, показано на Л5; тут ви дописуєте пʼять TODO.

## Запуск

Два термінали. Сервер уже готовий - це ваш проєкт із Пз4.

```bash
# термінал 1, не забудьте запустити Docker для другого рядка команд
cd server && cp .env.example .env && npm install
npx prisma generate && npx prisma migrate dev && npx prisma db seed
npm run dev                      # :3000

# термінал 2
cd client && npm install
npm run dev                      # :5173 - відкривати ЦЮ адресу
```

Демонстраційний користувач із seed: `demo@example.com`, пароль `demo1234`.

Відкривати треба `http://localhost:5173`, а **не** `index.html` з диска:
проксі `/api` і модулі працюють лише через dev-сервер.

## Підказки

**`npm install` - до будь-якої команди `npx prisma`.** Без установлених
залежностей `npx` мовчки тягне з реєстру НАЙСВІЖІШУ версію CLI (зараз це
Prisma 8), у якої інші команди - і ви отримаєте «No command registered for
`migrate`». Локальна CLI ставиться разом із залежностями.

**CORS у деві означає, що немає проксі.** Якщо в консолі зʼявилося слово CORS -
ви або відкрили `index.html` файлом, або стукаєте на `http://localhost:3000`
замість `/api`. Шлях у `fetch` має починатися з `/api`.

**`fetch` не кидає помилку на 404 і 500.** Він відхиляє обіцянку лише коли
мережа впала. Перевіряйте `res.ok` самі - інакше `catch` ніколи не спрацює,
а на екрані буде `undefined`.

**Ефект спрацював двічі - це `StrictMode`.** Тільки в dev, і це навмисно:
так React шукає ефекти, які не прибирають за собою.

**`Content-Type` лише коли є тіло.** На порожньому `GET` із цим заголовком
Fastify спробує розпарсити JSON і відповість `400`.

**204 не має тіла.** `res.json()` на відповіді `DELETE` впаде.

**Ключ - це `note.id`, а не індекс.** З індексом після видалення першого
запису React переплутає рядки, і стан «поїде» на сусідню картку.

**Стан піднімають, а не опускають.** Список і запити живуть у сторінці,
картка лише повідомляє про клік. Тому картка нічого не знає ні про API,
ні про токен.

## Чого тут немає - і це навмисно

- **роутера.** Адреси, історія і кнопка «назад». Сьогодні
  перемикання екранів - це один тернарник;
- **бібліотеки для даних.** `useEffect` + `useState` руками - щоб на Пз6
  було видно, що саме TanStack Query робить за вас;
- **глобального стану.** Токен лежить у `localStorage`, і по нього ходить
  `api/client.ts`. Zustand зʼявиться на Пз6;
- **обовʼязкових тестів.** Тест компонента - зірочка.


## Що здаємо

Репозиторій, у якому клієнт і сервер живуть поруч, `npm run build` у `client/`
проходить без помилок, а всі шість перевірок вище - теж.
