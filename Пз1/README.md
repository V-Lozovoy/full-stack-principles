Сервер вашого майбутнього проєкту. Це **не готовий проєкт**: процес стартує,
але порт не відкриває, і `/api/health` не існує. Довести це до робочого

## Як запустити

```bash
cd server
npm install
npm run dev            # tsx watch; процес живий, але порт поки не слухає
```

Node – 22.12 або новіший. `package-lock.json` лежить у `server/`: версії
зафіксовані до патча, тому у всій групі ставиться те саме. Лок-файл не видаляйте –
комітьте разом із рештою.

## Як перевірити себе

Один `curl` – цього на Пз1 достатньо, окремого скрипта перевірки немає:

```bash
curl -i http://localhost:3000/api/health
```

На чистому каркасі `curl` не отримує нічого (`Connection refused`, код `000`) –
порт ніхто не відкрив. Коли з'явиться TODO(2), той самий curl почне повертати
`404` – і це прогрес: сервер уже відповідає, просто маршруту ще немає. Здано,
коли відповідь – `HTTP/1.1 200 OK` і тіло з `"status":"ok"`:

```
HTTP/1.1 200 OK
Content-Type: application/json; charset=utf-8

{"status":"ok","uptime":12.4}
```

Сервер слухає інший порт – питайте його за тим адресою, яку він надрукував у лозі.
