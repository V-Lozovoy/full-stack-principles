# Точка старту Пз6

Клієнт у цій теці — це **робоче рішення Пз5**: `useState`, `useEffect`, `load()`
руками і тернарник замість маршрутів. Запустіть його першим ділом і переконайтесь,
що він працює: `npm run dev`.

Задача Пз6 — перевести його на три бібліотеки (React Router, Zustand,
TanStack Query) і додати мапу з маркерами на react-leaflet — усе вже
 стоїть у `package.json`. Провайдери та дефолти `QueryClient` у `main.tsx`
уже готові. Порядок кроків — у README практичної; після кожного кроку
застосунок має лишатися робочим.
